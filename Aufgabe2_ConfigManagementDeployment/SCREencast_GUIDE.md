# Screencast-Guide – Aufgabe 2 (max. ~3–5 Min.)

1) Terminal: `scripts/deploy.sh v1` → App v1 läuft.
2) Git (optional): zeige Tags/Branches für v1/v2.
3) Terminal: `scripts/deploy.sh v2` → Update; dann `scripts/rollback.sh v1` → Rollback.
4) Kurzer Wrap-up: Versionierung & Rollback vollständig automatisiert.

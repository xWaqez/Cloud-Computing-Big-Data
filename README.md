# Cloud Computing & Big Data – Aufgaben 1–3

Dieses Paket enthält eine vollständige, nachvollziehbare Lösung für die Aufgaben 1–3 mit eigener Dokumentation je Aufgabe.
Die drei Aufgaben sind **klar getrennt** (eigene Ordner), greifen jedoch konzeptionell aufeinander auf (gleiche Demo-Anwendung & Versionierung).

- **Aufgabe 1:** Immutable Infrastructure mit Terraform + Packer + Docker
- **Aufgabe 2:** Erweiterung um Anwendungsinstallation, Versionierung & Rollback
- **Aufgabe 3:** Kubernetes-Microservice auf OpenStack inkl. Ingress & Skalierung

> Keine externen Links erforderlich; alle Manifeste und Skripte sind lokal enthalten. Container-Images können lokal gebaut und in eine mitgelieferte Registry gepusht werden.
